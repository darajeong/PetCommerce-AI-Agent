# W2-A02 테스트 상품 데이터 (합성)

- 파일: `W2-A02_TEST_PRODUCT_001.json`(하네스), `002`(방석), `003`(씹는 장난감), 생성 스크립트 `make_w2_a02_test_products.py`
- 구조: W1-04 v0.1. 모든 값은 `data_type: "test"`이며 실제 상품·판매자·리뷰·상표가 아니다. URL은 `example.com`, 판매자는 `TEST Supplier`로 합성했다.
- 용도: W1-07 대체 경로(수동 입력이 어려운 항목)와 Agent 연계 개발용.

## 사용 제한

- **이 파일은 대체 경로·개발용이며 A02·A03·B02 PoC 판정(서로 다른 실제 상품 3건 기준)을 대체하지 않는다.** 이 데이터로 통과한 결과를 W5 판정의 실제 증빙으로 쓰지 않는다.
- B02 반복 불만(버클 파손, 충전재 꺼짐, 조각 떨어짐 등)은 의도적으로 넣은 값이라 정답이 정해져 있다. 분석 품질 평가에 쓰려면 이 점을 기록에 함께 적는다.
- 환율은 테스트용 고정값(1 USD = 1,400 KRW)이며 실제 가격 결정에 쓰지 않는다.

## 상태값

- `run.status`와 A02·A03의 `status`는 `success`로 두었다. 일부 원본 필드가 `null`이고 `missing_fields`에 사유가 있어도, **해당 단계의 처리 자체는 끝났다는 의미**로 썼다.
- 누락이 있을 때 `success`와 `partial_success`를 나누는 기준은 W1-04 v0.2에서 정하고, 정해지면 이 파일의 상태를 맞춘다.

## 검증 범위

- `python docs/poc/samples/make_w2_a02_test_products.py docs/poc/samples` 실행 시 자체 점검을 함께 한다. 점검 항목: `field_meta` 경로 존재, 누락 필드 값이 비어 있는지, `rights_status` 요약과 `usage` 일치, 번역 리뷰 ID와 원본 일치, 변환 원본값·계산, `normalized_dimensions`와 변환 결과 일치.
- 자체 점검이 다루지 않는 항목: 누락 사유 없는 빈 값, 정의 밖 상태값·누락 사유 코드, 시각 형식, 근거(`evidence`) 연결. 이 항목은 `validate_w1_04.py`의 단계별 검사 모드(`--stage A02`·`A03`, W1-04 v0.2 예정)가 생기면 그쪽으로 합치고 자체 점검은 줄인다.
- 원본이 `null`인 값은 정규화 값도 `null`이다(001의 크기 전체, 003의 폭·높이). 각 경로는 `missing_fields`에 개별 기록했다.
- W1-04 v0.2에서 권장 체중이 `{value, unit}` 객체로 바뀌면 이 파일과 스크립트를 함께 갱신한다.
