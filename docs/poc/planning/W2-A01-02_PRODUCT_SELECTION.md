## 2. 비교 기준

| 항목 | 기록 방법 |
|---|---|
| 가격 | 상품 페이지의 표시 가격 범위와 통화 |
| 판매량 | 상품 페이지에 표시된 판매 수 (`N sold`). 없으면 `미표시` |
| 평점 | 상품 자체 평점과 리뷰 수. 공급업체 평점만 있으면 `상품 평점 미표시 (공급업체 x.x/5.0)`로 구분 |
| 유사성 | 쿠팡에서 같은 유형 대형견 상품을 검색해 유사 상품 존재 여부와 가격대 기록 |
| 신규성 | 유사성 결과로 판단. 국내 유사 상품이 적을수록 높음 (상·중·하) |

평가 항목 값이 없으면 빈칸으로 두지 않고 `미표시` 또는 `확인 불가`와 사유를 적는다. 사유가 있는 값은 누락으로 보지 않는다.

**선정 이유에 함께 반영하는 조건:** 선정 3개는 서로 다른 유형(하네스·방석·장난감 각 1개)이며 대형견용 표기가 있는 상품으로 한다. W3 B04-02가 서로 다른 상품 유형 3개에 대형견 기준을 적용하기 때문이다. 대형견 표기는 A01-01 목록 제목 기준이다.

이미지·리뷰 확보와 사용 범위는 A02-03에서 확인하며 이 문서의 범위가 아니다.
