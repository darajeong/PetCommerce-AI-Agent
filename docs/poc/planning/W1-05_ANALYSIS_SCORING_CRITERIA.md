## 1. 문서 목적

본 문서는 PetCommerce AI Agent에서 상품의 경쟁력과 국내 판매 적합성을 일관된 기준으로 평가하기 위한 분석·점수화 기준을 정의한다.

특정 상품 유형 하나만 평가하는 것이 아니라, 프로젝트에서 다루는 전체 반려견 상품을 대상으로 한다.

다만 상품 유형에 따라 평가해야 하는 특성이 다르므로 공통 평가 기준과 상품 유형별 추가 기준을 함께 적용한다.

주요 목적은 다음과 같다.

1. 상품 이미지, 상세 설명 및 리뷰를 바탕으로 상품의 특징과 장단점을 분석한다.
2. 상품 유형에 맞는 대형견 적합성을 평가한다.
3. 가격, 디자인, 리뷰, 적합성, 국내 판매 가능성을 100점 기준으로 점수화한다.
4. 모든 점수에 확인 가능한 근거를 연결한다.
5. 정보가 부족하거나 안전 위험이 있는 상품은 무리하게 높은 점수를 부여하지 않는다.
6. 동일한 입력에 대해 일관된 분석 결과와 점수가 나오도록 한다.

## 2. 평가 대상 및 기본 원칙

### 2.1 평가 대상

특정 상품 유형을 사전에 하나로 제한하지 않는다.

예시:
- 반려견 침대 및 방석
- 하네스 및 목줄
- 장난감
- 식기 및 급수 용품
- 산책 용품
- 위생 및 관리 용품
- 기타 반려견 관련 상품

상품 유형을 먼저 분류한 뒤 해당 유형에 적합한 평가 기준을 적용한다.

### 2.2 상품 유형별 평가 원칙

공통 평가 기준을 유지하되 상품 유형별로 세부 평가 항목과 판단 기준을 다르게 적용한다.

예시:

| 상품 유형 | 추가로 고려할 사항 |
|---|---|
| 침대 | 크기, 쿠션감, 하중, 미끄럼 방지, 세척 |
| 하네스 | 가슴둘레, 목둘레, 연결 부위, 버클, 하중 |
| 장난감 | 소재, 내구성, 파손 및 삼킴 위험 |
| 식기 | 소재 안전성, 안정성, 크기, 세척 편의성 |
| 산책 용품 | 연결 강도, 내구성, 사용 편의성 |

기존 카테고리로 분류할 수 없는 상품은 AI가 새로운 유형을 제안하고 담당자가 검토한 후 평가 기준을 적용한다.

### 2.3 공통 원칙

- 실제 데이터와 Mock 데이터를 명확히 구분한다.
- 원본 정보에 없는 사양, 수치, 인증 및 효능을 임의로 생성하지 않는다.
- 모든 주요 평가 결과에 원본 근거를 연결한다.
- 확인되지 않은 비용과 정보는 추측하지 않는다.
- 안전 및 법규 관련 최종 판단은 사람이 수행한다.
- 평가 불가능한 항목은 0점으로 처리하지 않고 별도 표시한다.

## 3. 전체 평가 항목 및 배점

전체 점수는 100점이며 다음 5개 영역으로 구성한다.

| 평가 영역 | 배점 | 주요 평가 내용 |
|---|---:|---|
| 가격 | 20점 | 가격 경쟁력, 가격 대비 품질, 기능·구성 |
| 디자인 | 20점 | 외관, 소재, 구조, 실용성 |
| 리뷰 | 20점 | 긍정·부정 평가, 반복 장점 및 불만 |
| 대형견 적합성 | 25점 | 체형, 하중, 내구성, 안전, 사용성 |
| 국내 판매 가능성 | 15점 | 시장 수요, 가격 포지셔닝, 법규·인증 |
| **합계** | **100점** | |

## 4. 공통 점수 척도

모든 세부 평가 항목은 기본적으로 0~5점 척도를 사용한다.

| 점수 | 평가 수준 | 판단 기준 |
|---:|---|---|
| 0점 | 기준 미충족 | 확인된 정보상 평가 기준을 충족하지 못함 |
| 1점 | 매우 부족 | 중요한 단점이나 문제가 확인됨 |
| 2점 | 부족 | 개선이 필요한 부분이 다수 존재함 |
| 3점 | 보통 | 기본적인 기준을 충족함 |
| 4점 | 우수 | 대부분의 기준을 충족하고 경쟁력이 있음 |
| 5점 | 매우 우수 | 평가 기준을 충분히 충족하고 뚜렷한 강점이 있음 |

평가에 필요한 정보가 없는 경우에는 0점을 부여하지 않는다.

다음과 같이 구분한다.

- 평가 가능: 0~5점 부여
- 평가 불가: N/A 처리 및 사유 기록
- 추가 확인 필요: 잠정 평가 및 검토 요청

### 4.1 가중치 환산

세부 평가 점수는 다음과 같이 배점으로 환산한다.

`환산 점수 = (세부 평가 점수 / 5) × 해당 항목 배점`

예를 들어 5점 만점인 항목에서 4점을 받으면 배점이 5점인 경우 4점으로 환산한다.

## 5. 가격 평가 기준 (20점)

### 5.1 평가 목적

해외 상품을 국내에서 판매한다고 가정했을 때 가격 경쟁력이 있는지 판단한다.

단순 구매 가격이 아닌 해외 구매부터 국내 도착까지 발생하는 기본 비용과 국내 유사 상품의 가격을 비교한다.

### 5.2 세부 배점

| 세부 항목 | 배점 | 평가 내용 |
|---|---:|---|
| 가격 경쟁력 | 10점 | 국내 경쟁 상품 대비 원가 비율과 가격 차액 |
| 가격 대비 품질 | 5점 | 가격 대비 소재, 내구성, 품질 수준 |
| 가격 대비 기능·구성 | 5점 | 가격 대비 기능, 구성품 및 활용성 |
| **합계** | **20점** | |

### 5.3 기본 도착 원가

기본 도착 원가는 다음 항목을 포함한다.

`기본 도착 원가 = 해외 상품 구매 가격 + 국제 배송비 + 관세·수입 관련 세금 + 국내 배송비`

다음 항목은 기본 도착 원가에 포함하지 않고 별도 참고 정보로 관리한다.

- 플랫폼 수수료
- 결제 수수료
- 포장 및 물류 비용

확인된 비용과 예상 비용은 반드시 구분한다.

확인할 수 없는 비용은 임의로 계산하지 않고 누락 항목으로 기록한다.

### 5.4 국내 경쟁 상품 비교 기준

국내 경쟁 상품은 다음 조건을 만족해야 한다.

1. 동일한 상품 카테고리
2. 유사한 크기 및 규격
3. 주요 기능이 유사한 상품

비교 대상은 국내 유사 상품 최소 5개를 권장한다.

5개 미만인 경우에도 확보한 상품으로 평가할 수 있지만, 실제 확보 수량과 부족 사유를 기록하고 신뢰도를 낮춘다.

### 5.5 경쟁 상품 가격 기준

국내 경쟁 상품은 유사 상품 중 최저 가격을 기준으로 한다.

실제 소비자가 지불하는 금액을 기준으로 하며 국내 배송비를 포함한다.

할인 가격은 다음과 같이 구분한다.

- 일반 판매 가격: 기본 비교 가격
- 할인 적용 가격: 별도 참고 가격

회원 전용 또는 특정 조건을 충족해야 하는 할인은 일반 판매 가격과 구분한다.

### 5.6 가격 경쟁력 계산

다음 두 지표를 함께 활용한다.

**① 원가 비율**

`원가 비율 = 기본 도착 원가 / 국내 유사 상품 최저 가격 × 100`

**② 가격 차액**

`가격 차액 = 국내 유사 상품 최저 가격 - 기본 도착 원가`

예시:

- 기본 도착 원가: 30,000원
- 국내 유사 상품 최저 가격: 45,000원

원가 비율: 66.7%

가격 차액: 15,000원

가격 차액은 실제 순이익이 아니라 국내 최저 가격 대비 기본 도착 원가의 차이다.

가격 경쟁력 10점은 다음과 같이 나눈다.

| 평가 기준 | 배점 |
|---|---:|
| 원가 비율 | 5점 |
| 가격 차액 | 5점 |
| 합계 | 10점 |

세부 점수 구간은 실제 PoC 상품을 비교한 후 보정한다.

## 6. 디자인 평가 기준 (20점)

### 6.1 평가 목적

상품의 외관, 소재, 구조 및 실용성을 평가한다.

단순히 예쁘거나 독특한 디자인인지가 아니라 상품의 목적과 사용 환경에 적합한지도 함께 고려한다.

### 6.2 세부 배점

| 평가 항목 | 배점 | 평가 내용 |
|---|---:|---|
| 외관 및 심미성 | 5점 | 디자인 완성도, 색상, 형태 |
| 소재 및 마감 | 5점 | 소재 특성, 마감 품질 |
| 구조 및 설계 | 5점 | 구조의 합리성, 안정성, 사용 목적 적합성 |
| 실용성 | 5점 | 사용 편의성, 관리 편의성 |
| **합계** | **20점** | |

상품 유형에 따라 세부 판단 기준을 다르게 적용한다.

예를 들어 침대는 쿠션 구조와 미끄럼 방지, 하네스는 연결 부위와 조절 구조를 중점적으로 평가한다.

이미지에서 확인할 수 없는 소재나 마감 품질은 확정하지 않고 추가 확인 대상으로 기록한다.

## 7. 리뷰 평가 기준 (20점)

### 7.1 평가 목적

실제 구매자의 경험을 바탕으로 상품의 장점, 단점 및 반복적인 문제를 파악한다.

### 7.2 세부 배점

| 평가 항목 | 배점 | 평가 내용 |
|---|---:|---|
| 긍정 평가 | 5점 | 긍정적인 사용자 경험과 만족도 |
| 부정 평가 | 5점 | 부정적인 경험과 불만 요소 |
| 반복 장점 | 5점 | 여러 리뷰에서 반복적으로 확인되는 장점 |
| 반복 불만 | 5점 | 반복적으로 발생하는 문제와 불만 |
| **합계** | **20점** | |

### 7.3 리뷰 데이터 기준

- 상품별 리뷰 20개 이상을 권장한다.
- 20개 미만인 경우 확보한 리뷰로 평가할 수 있다.
- 실제 리뷰와 Mock 리뷰를 구분한다.
- 실제 리뷰를 확보하지 못한 경우 Mock 데이터로 실제 구매자 만족도를 검증했다고 판단하지 않는다.

### 7.4 반복 불만 판정 기준

반복 불만은 다음 조건을 모두 만족할 때 표시한다.

- 동일하거나 유사한 불만이 최소 2건 이상 발생
- 전체 리뷰 대비 해당 불만 비율이 20% 이상

예시:

전체 리뷰가 20개이고 동일한 불만이 4건 발생한 경우:

`반복 불만 비율 = 4 / 20 × 100 = 20%`

반복 불만은 발생 건수와 비율을 함께 기록한다.

반복 불만의 발생만으로 안전상 중대한 위험이라고 단정하지 않는다. 위험 수준은 별도 검토한다.

## 8. 대형견 적합성 평가 기준 (25점)

### 8.1 평가 목적

상품이 대형견의 체형, 체중, 활동성 및 사용 환경에 적합한지 평가한다.

상품 유형에 따라 세부 기준을 다르게 적용한다.

### 8.2 세부 배점

| 평가 항목 | 배점 | 평가 내용 |
|---|---:|---|
| 체형·크기 적합성 | 5점 | 대형견 체형과 상품 크기의 적합성 |
| 체중·하중 | 5점 | 권장 체중, 허용 하중 및 지지 능력 |
| 내구성 | 5점 | 소재 및 구조의 내구성 |
| 안전성 | 5점 | 사용 중 위험 요소 및 구조적 안전성 |
| 사용·관리 편의성 | 5점 | 사용 편의성 및 세척·관리 |
| **합계** | **25점** | |

### 8.3 상품 유형별 적용

공통 기준을 유지하면서 상품 유형별 특화 기준을 추가한다.

예시:

| 상품 유형 | 중점 평가 사항 |
|---|---|
| 침대 | 크기, 하중, 쿠션감, 미끄럼 방지 |
| 하네스 | 체형 적합성, 연결 강도, 버클, 조절 범위 |
| 장난감 | 파손 위험, 소재, 삼킴 위험 |
| 식기 | 크기, 안정성, 소재, 세척 |
| 산책 용품 | 하중, 연결 강도, 내구성 |

적용할 수 없는 항목은 사유를 기록하고 평가 불가로 처리한다.

### 8.4 안전 위험 처리

안전 위험이 의심되는 경우 다음 원칙을 적용한다.

1. AI가 위험 요소를 발견하면 해당 상품의 추천을 우선 보류한다.
2. 위험이 발생한 원본 근거와 의심 사유를 기록한다.
3. 담당자가 관련 자료를 확인한다.
4. 사람의 검토 후 추천 가능 여부를 결정한다.

AI가 안전성을 최종 확정하거나 인증을 보장하지 않는다.

## 9. 국내 판매 가능성 평가 기준 (15점)

### 9.1 평가 목적

상품이 국내 시장에서 판매될 가능성이 있는지 종합적으로 평가한다.

### 9.2 세부 배점

| 평가 항목 | 배점 | 평가 내용 |
|---|---:|---|
| 국내 시장 수요 | 7점 | 시장 관심도, 수요 신호, 경쟁 상품 현황 |
| 가격 포지셔닝 | 5점 | 국내 시장에서의 목표 가격 위치와 경쟁력 |
| 법규·인증 제약 | 3점 | 국내 판매 시 확인해야 하는 규제 및 인증 사항 |
| **합계** | **15점** | |

### 9.3 평가 시 주의 사항

가격 경쟁력 20점과 중복 평가하지 않도록 한다.

- 가격 20점: 실제 원가와 국내 경쟁 가격의 비교
- 판매 가능성 15점: 국내 시장에서의 상품 포지셔닝과 판매 제약

법규 및 인증 항목은 확인 필요 사항을 분류하는 수준으로 평가한다.

AI는 법규 준수나 인증 취득 여부를 최종 확정하지 않으며, 사람의 검토가 필요하다.

## 10. 정보 부족 및 잠정 점수 처리

### 10.1 기본 원칙

평가 근거가 부족하다는 이유만으로 0점을 부여하지 않는다.

확인 가능한 항목은 점수화하고 평가할 수 없는 항목은 별도로 표시한다.

### 10.2 잠정 점수 계산

평가 가능한 항목의 환산 점수만 합산한다.

예시:

| 항목 | 배점 | 획득 점수 |
|---|---:|---:|
| 가격 | 20점 | 16점 |
| 디자인 | 20점 | 15점 |
| 리뷰 | 20점 | 평가 불가 |
| 대형견 적합성 | 25점 | 19점 |
| 국내 판매 가능성 | 15점 | 11점 |

잠정 점수: 61점 / 평가 가능 배점 80점

이 경우 100점 만점의 확정 점수로 표시하지 않는다.

평가 불가 항목과 사유를 함께 표시하고 최종 등급은 확정하지 않는다.

## 11. 데이터 신뢰도 기준

데이터 신뢰도는 다음 세 가지를 종합해 평가한다.

1. 데이터 확보량
2. 출처의 신뢰성과 추적 가능성
3. 주요 평가 근거의 확보 여부

| 신뢰도 | 판단 기준 |
|---|---|
| 높음 | 필요한 데이터가 충분하고 주요 평가 근거가 원본과 연결됨 |
| 보통 | 일부 데이터가 부족하지만 주요 항목은 평가 가능함 |
| 낮음 | 핵심 데이터가 부족하거나 Mock 데이터 의존도가 높음 |

다음 사항을 함께 기록한다.

- 실제 데이터 사용 여부
- 이미지 확보 수량
- 리뷰 확보 수량
- 국내 비교 상품 확보 수량
- 출처 및 근거 연결 상태
- 평가 불가 항목

신뢰도는 점수와 별도로 표시하며, 점수를 임의로 높이거나 낮추는 보정 수단으로 사용하지 않는다.

## 12. 상품 등급 및 최종 판정

### 12.1 등급 기준

| 등급 | 점수 | 의미 |
|---|---:|---|
| A | 85~100점 | 경쟁력이 매우 높은 상품 |
| B | 70~84점 | 기본 경쟁력을 갖춘 상품 |
| C | 70점 미만 | 개선 또는 추가 검토가 필요한 상품 |

### 12.2 등급 판정 원칙

- 전체 100점 평가가 가능한 경우 등급을 확정한다.
- 평가 불가 항목이 있으면 잠정 점수로 표시한다.
- 잠정 점수만으로 최종 등급을 확정하지 않는다.
- 안전 위험이 의심되면 점수와 관계없이 추천을 보류한다.
- 최종 추천 가능 여부는 사람의 검토 결과를 반영한다.

### 12.3 최종 출력 항목

B05는 다음 정보를 출력한다.

| 출력 항목 | 내용 |
|---|---|
| 상품 정보 | 상품 ID, 상품명, 유형 |
| 종합 점수 | 총점 또는 잠정 점수 |
| 등급 | A/B/C 또는 미확정 |
| 가격 점수 | 가격 경쟁력 및 산출 근거 |
| 디자인 점수 | 디자인 세부 점수 |
| 리뷰 점수 | 긍정·부정·반복 불만 |
| 적합성 점수 | 대형견 적합성 및 근거 |
| 판매 가능성 | 국내 판매 가능성 평가 |
| 주요 장점 | 확인된 경쟁력 |
| 주요 단점 | 확인된 약점 |
| 안전 위험 | 위험 요소 및 검토 상태 |
| 정보 부족 | 추가 확인이 필요한 항목 |
| 신뢰도 | 높음·보통·낮음 |
| 최종 판정 | 추천·조건부 추천·보류 |

## 13. B그룹 Agent 연계 기준

B그룹의 각 Agent는 다음과 같이 연결한다.

| Agent | 역할 | B05 전달 데이터 |
|---|---|---|
| B01 | 이미지·상품 분석 | 디자인, 소재, 구조, 특징, 이미지 근거 |
| B02 | 리뷰 분석 | 긍정·부정, 반복 장점·불만, 리뷰 근거 |
| B04 | 대형견 적합성 분석 | 크기, 하중, 내구성, 안전, 사용성 |
| B05 | 종합 점수화 | 전체 평가 결과 및 최종 점수 |

B05는 B01·B02·B04의 결과를 활용하되, 근거가 누락된 결과를 확정된 사실로 취급하지 않는다.

각 결과는 원본 상품 정보 및 실행 ID와 연결할 수 있어야 한다.

## 14. 반복 실행 및 재현성 검증

동일한 상품과 동일한 입력 데이터를 사용하여 3회 반복 실행한다.

| 검증 항목 | 기준 |
|---|---|
| 상품명 및 주요 사양 | 핵심 사실 불일치 0건 |
| 분석 항목 | 동일한 평가 항목 유지 |
| 근거 연결 | 주요 결과의 원본 근거 확인 |
| 총점 변동 | 3회 실행의 최대·최소 차이 5점 이내 |
| 결과 차이 | 차이가 발생하면 원인 기록 |
| 재현성 | 다른 팀원 1명 이상 재실행 가능 |

기준을 충족하지 못하면 프롬프트, 평가 규칙, 입력 데이터의 차이를 확인하고 보완한다.
