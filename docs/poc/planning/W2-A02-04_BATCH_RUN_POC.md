## 5-4. 실행 절차와 소스

| 단계 | 수행 내용 | 방식 | 출력 |
|---|---|---|---|
| access | A02-01 결과로 차단·수동 대체 경로 기록 | 기록 (재실행 안 함) | 실행 로그 `events[]` |
| facts | 입력표 → W1-04 상품 JSON (`a02_build_product.build`) | 자동 | `W2-A02-02_PRODUCT_prod-w2-0n.json` |
| normalize | A03-02 정규화 (`a03_normalize.normalize`, 환율 인자 없음) | 자동 | `W2-A03-02_RESULT_w2-0n.json` |

```powershell
python docs/poc/samples/a02_batch_run.py --self-test
python docs/poc/samples/a02_batch_run.py
```

- 소스: `docs/poc/samples/a02_batch_run.py`. 기존 A02-02 빌더와 A03-02 정규화 함수를 그대로 불러 쓴다.
- 단계가 예외로 실패하면 1회 재시도하고, 그래도 실패하면 그 상품만 `failed`로 저장한 뒤 다음 상품으로 넘어간다.
- 단계 밖(결과 저장·최종 상태 계산)에서 예외가 나도 그 상품만 `failed`(`record` 단계)로 기록하고 다음 상품으로 넘어간다.
- 로그는 상품 하나를 끝낼 때마다 파일에 다시 쓴다. 중간에 프로세스가 죽어도 앞 상품의 최종 상태는 파일에 남고 `completed: false`로 표시된다.
- 상품 JSON·정규화 결과는 PR #12 파일과 같은 경로에 저장하되, 기존 파일과 내용이 다르면 덮어쓰지 않고 `warnings[]`에 남긴다(`--overwrite`를 줄 때만 갱신). PR #12의 검토 완료 결과가 조용히 바뀌지 않게 하기 위해서다.
