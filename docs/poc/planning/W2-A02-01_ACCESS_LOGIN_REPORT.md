## 2. 판정

## 4. 검증 결과

### 4.1 비로그인 헤드리스

각 상품을 별도 비로그인 브라우저 컨텍스트에서 확인했다.

| 상품 | 수행 방식 | 관찰 시작 시각(KST) | HTTP 상태 | 결과 |
|---|---|---|---|---|
| 하네스 | 자동 | 22:30:10 | 200 | 보안 확인 관련 문구 감지 후 중단 |
| 방석 | 자동 | 22:40:16 | 200 | 보안 확인 관련 문구 감지 후 중단 |
| 장난감 | 자동 | 22:40:21 | 200 | 보안 확인 관련 문구 감지 후 중단 |

기존 보고서에는 세 건 모두 `security_challenge: true`와 `outcome: access_restricted`가 기록돼 있다. HTTP 403·429는 기록되지 않았다. HTTP 200, 상품 ID, 제목 요소 감지만으로 정상 접근 성공을 판정하지 않았다.

### 4.2 일반 크롬 수동 확인

| 항목 | 수행 방식 | 결과 |
|---|---|---|
| 하네스 접근 | 수동 | 비정상 트래픽 안내 표시. 직접 슬라이더 인증 후 상품 페이지 열림 |
| 방석·장난감 접근 | 수동 | 상품 페이지 바로 열림 |
| 로그인 후 접근 | 수동 | 상품 3개 모두 열림 |
| 전화 인증 | 수동 | 이번 수동 로그인에서는 요구되지 않음 |
| 세션 유지 | 수동 | 같은 로그인 창에서 방석·장난감 이동 및 새로고침 후 로그인 유지 |
| 지역 제한 | 수동 | 접속 국가 KR. 명시적인 지역 제한 안내는 관찰되지 않음 |

### 4.3 로그인 후 헤드리스 참고 테스트

| 수행 방식 | 관찰 시각(KST) | 결과 |
|---|---|---|
| 수동 준비 / 자동 실행 없음 | 22:52–22:53 | 테스트 브라우저의 로그인 준비 중 비정상 트래픽 안내가 표시됐다. 직접 슬라이더를 조작한 뒤 오류가 발생해 로그인 준비를 종료했다. 로그인 후 헤드리스 상품 조회는 실행하지 않았다. |

**플랫폼 자동 접근 감지 추정.** 로그인 후 헤드리스 테스트를 준비하던 브라우저에서 비정상 트래픽 안내가 나왔고, 슬라이더 인증 후에도 오류가 발생해 로그인을 완료하지 못했다. 일반 크롬에서도 하네스에 같은 안내가 나왔지만, 직접 인증한 뒤 상품 페이지가 열렸다. 정확한 차단 원인은 확인되지 않았다.

이 시도는 **참고 테스트, 추가 실행 없음**으로 분류한다.

## 6. 증빙

실행별 원본 JSON은 현재 확인할 수 없다. 실행 시각, HTTP 상태, 중단 사유는 기존 보고서에 기록된 내용을 근거로 제시한다. 일반 크롬에서의 접근 결과는 실행자가 직접 확인한 내용으로 구분한다.

| 기존 보고서의 실행 식별자 | 수행 방식 | 기록 내용 |
|---|---|---|
| `20261108_223009` | 자동 | 하네스 비로그인 헤드리스 결과 |
| `20261108_224015_product_7` | 자동 | 방석 비로그인 헤드리스 결과 |
| `20261108_224015_product_9` | 자동 | 장난감 비로그인 헤드리스 결과 |
| `20261108_225206_after_login` | 수동 준비 | 로그인 준비 미완료 및 로그인 후 자동 검사 미실행 |

기존 보고서에는 보안 확인 관련 문구가 감지됐다는 결과만 남아 있으며, 감지에 사용한 키워드나 셀렉터는 기록되어 있지 않다. 방석과 장난감은 일반 크롬에서 바로 열렸다. 헤드리스에서는 실제 차단 여부를 확인하지 못했으므로, 자동 감지 결과에 오탐 가능성이 있다.

## 7. 미확인·한계

- 일반 크롬 세션 확인은 같은 창에서의 짧은 이동과 새로고침 범위다. 장시간, 브라우저 재시작 후, 자동 환경에서의 세션 유지는 확인하지 않았다.
- 지역 제한은 한국(KR) 접속에서 관찰한 결과다. 다른 국가에서의 접근 여부는 확인하지 않았다.
- 원본 JSON과 탐지 규칙을 확인할 수 없어 자동 감지의 정확도와 차단 원인을 확정할 수 없다.

## 8. 후속

- 검토 담당 C에게 일반 크롬 수동 확인 결과와 상품별 대체 경로가 완료 기준을 충족하는지 재검토를 요청한다.
- 비정상 트래픽 안내가 관찰된 자동 접근은 재시도하지 않는다.
