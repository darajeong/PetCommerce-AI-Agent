# W2-A02-01 실제 상품 3건 접근·로그인 검증 기록

## 개요

A02-01의 실제 상품 URL 3개를 대상으로 비로그인 헤드리스 접근을 시도하고, 일반 크롬에서 수동 접근·로그인·세션 유지 여부를 확인했습니다.

**현재 판정은 부분 검증입니다.** 비로그인 헤드리스에서는 세 상품 모두 보안 확인 관련 문구가 감지됐습니다. 로그인 후 헤드리스 검사는 별도 테스트 브라우저의 로그인 준비 단계에서 보안 확인 오류가 발생해 수행하지 못했습니다.

## 실행 환경

- 실행일: 2026-11-08 (KST)
- 담당: B·다라
- 운영체제: macOS 26.6.2 / ARM64

## 검증 결과

### 비로그인 헤드리스 접근

각 상품을 별도 비로그인 브라우저 컨텍스트에서 확인했습니다.

| 상품  | 관찰 시작 시각(KST) | HTTP 상태 | 실행 결과               |
| --- | ------------- | ------- | ------------------- |
| 하네스 | 22:30:10      | 200     | 보안 확인 관련 문구 감지 후 중단 |
| 방석  | 22:40:16      | 200     | 보안 확인 관련 문구 감지 후 중단 |
| 장난감 | 22:40:21      | 200     | 보안 확인 관련 문구 감지 후 중단 |

세 상품 모두 JSON에 `security_challenge: true`, `outcome: access_restricted`가 기록됐습니다. HTTP 403·429는 기록되지 않았습니다.

상품 ID와 보이는 제목 요소도 함께 감지됐으나, HTTP 200과 제목 요소만으로 정상 접근 성공을 판정하지 않았습니다. 감지한 정확한 문자열과 인증 화면은 저장하지 않아, 특히 방석·장난감의 실제 화면 차단 여부와 탐지 오탐 가능성은 확정하지 못했습니다.

### 일반 크롬 수동 확인

다음은 실행자가 직접 확인한 내용이며, 자동 측정 결과와 구분합니다.

| 항목        | 확인 결과                                   |
| --------- | --------------------------------------- |
| 하네스 접근    | 비정상 트래픽 안내가 표시됐고, 직접 슬라이더 인증 후 상품 화면 열림 |
| 방석·장난감 접근 | 상품 화면 바로 열림                             |
| 로그인 후 접근  | 상품 3개 모두 열림                             |
| 전화 인증     | 이번 수동 로그인에서는 요구되지 않음                    |
| 세션 유지     | 같은 로그인 창에서 방석·장난감 이동·새로고침 후 로그인 유지      |
| 지역 제한     | 명시적 제한은 확인하지 못했으며, 접속 지역도 미확인           |

세션 확인은 이번 실행 중 짧은 이동·새로고침 범위에 한정합니다. 장시간 또는 브라우저 재시작 후 세션 유지는 검증하지 않았습니다.

### 로그인 후 헤드리스 미실행 사유

22:52\~22:53 KST에 로그인 후 헤드리스 검사를 준비하기 위해 별도 가시 브라우저를 열었습니다.

- “회원님의 네트워크에서 비정상적인 트래픽이 감지되었습니다”라는 안내가 표시됐습니다.
- 사람이 직접 슬라이더를 조작했으나 ‘웁스, 잘못되었다’는 취지의 오류가 발생했습니다. 정확한 오류 원문·코드는 확보하지 못했습니다.
- 로그인하지 못해 `n`을 입력하고 종료했습니다.
- JSON에 `login_step: 사용자 로그인 미완료`와 상품 3개의 로그인 후 `not_tested`가 저장됐습니다.

이는 **로그인 준비 단계 실패**이며, 로그인 후 헤드리스 요청을 수행한 결과는 아닙니다. 다른 일반 크롬에서는 같은 URL이 열렸지만, 차이의 원인이 IP·세션·자동화 감지 중 무엇인지는 확정하지 못했습니다.

수동 접근 성공은 헤드리스 접근 성공과 구분해 기록했습니다.

## 증빙

실행별 원본 JSON은 다음과 같습니다.

| 실행 폴더                         | 내용                        |
| ----------------------------- | ------------------------- |
| `20261108_223009`             | 하네스 비로그인 헤드리스 결과          |
| `20261108_224015_product_7`   | 방석 비로그인 헤드리스 결과           |
| `20261108_224015_product_9`   | 장난감 비로그인 헤드리스 결과          |
| `20261108_225206_after_login` | 로그인 준비 미완료 및 로그인 후 검사 미실행 |

각 폴더의 기본 결과 파일명은 `A02-01_RESULT.json`입니다. 마지막 실행의 비로그인 `not_tested`는 해당 실행에서 비로그인 검사를 반복하지 않았다는 뜻이며, 앞선 실행 결과는 별도 증빙으로 유지합니다.

비밀번호·인증번호·쿠키·토큰·HTML 본문·상품 이미지·리뷰 원문은 결과 파일에 저장하지 않았습니다. 보안 확인은 사람이 직접 처리했으며 자동 인증·접근 제한 우회는 수행하지 않았습니다.

## 미검증 항목 및 검토 요청

- 로그인 후 헤드리스 상품 접근
- 자동 환경에서의 로그인 세션 유지
- 장시간·브라우저 재시작 후 세션 유지
- 접속 국가·지역과 지역 제한 유무
- 보안 확인 탐지의 정확도 및 제한 발생 원인

검토 담당 C님께 상품 3건의 접근 결과·제약·수동 대체 경로가 충분히 기록됐는지 검토를 요청드립니다. 로그인 후 자동 검사 미검증을 외부 제약으로 인정할 수 있는지, 조건부 완료 또는 추가 검증이 필요한지도 확인 부탁드립니다.

또한 작업 준비 시 확인한 [PR #3](https://github.com/darajeong/PetCommerce-AI-Agent/pull/3) 수정본의 W2 자동 접근 미사용 기준과 별도로 전달받은 헤드리스 테스트 지시 사이의 관계를 팀 기록에 명확히 정리할 필요가 있습니다.
