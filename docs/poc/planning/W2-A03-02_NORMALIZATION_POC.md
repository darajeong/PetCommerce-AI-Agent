## 5-4. 실행 절차와 소스

| 단계 | 수행 내용 | 방식 | 출력 |
|---|---|---|---|
| 1 | 자체 시험(기대값 21건 + 음성 사례 7건) | 자동 | 표준 출력 |
| 2 | 합성 3건 정규화 | 자동 | `W2-A03-02_RESULT_00n.json` |
| 3 | 실제 3건 정규화 (입력표 반영 후 재실행) | 자동 | 표준 출력 |

```powershell
python docs/poc/samples/a03_normalize.py --self-test
python docs/poc/samples/a03_normalize.py docs/poc/samples/W2-A02_TEST_PRODUCT_001.json --output docs/poc/samples/W2-A03-02_RESULT_001.json --rate USD:KRW=1400 --rate-source "테스트용 고정 환율(실제 환율 아님)"
python docs/poc/samples/a02_build_product.py
python docs/poc/samples/a03_normalize.py docs/poc/samples/W2-A02-02_PRODUCT_prod-w2-01.json
```

- 소스: `docs/poc/samples/a03_normalize.py`. 길이 mm·cm·m·in → cm, 무게 g·kg·lb·oz → kg, 가격은 `--rate`로 받은 환율만 적용(없으면 변환하지 않음).
- W1-04 v0.2 제안 필드(`normalized_pet_weight_max`, `normalized_material`, `duplicates`, `unconverted`)를 함께 쓴다. v0.2 확정 시 이름을 맞춘다.
