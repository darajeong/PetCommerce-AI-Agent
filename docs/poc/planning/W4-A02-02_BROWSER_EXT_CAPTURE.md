## 5-4. 실행 절차

1. 사람이 상세페이지를 직접 연다 (검색·이동도 사람).
2. 확장 아이콘 → 상품 ID 선택 → **사실 값 추출**. 확장은 JSON-LD → 페이지 데이터 → 화면 DOM 순으로 값을 찾고, 값마다 찾은 곳을 남긴다.
3. 사람이 화면과 대조. 이번 정확도 측정에서는 **고치지 않고** 저장한다.
4. `a02_capture_to_facts.py`로 통화·가격 검사 → 입력표 형식 CSV + 보고서.
5. 배송 방법·배송비·대형견 표기·용도는 사람이 입력표에 채운다.
6. `a02_build_product.py --out-dir <별도 폴더>` → `a03_normalize.py`.
