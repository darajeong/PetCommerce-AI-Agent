필수 8개 Agent 외에도 공통 데이터, 근거, 실행 상태, 오류 복구, 관리자 승인 및 통합 검증을 함께 확인한다.

| 필수 보조 기능 | 연결 PoC·선행 작업 |
|---|---|
| 공통 데이터 모델 | W1-04 |
| 근거 추적 | B01-01, B02-01, C02-02, C-INT-01 |
| 실행 상태·로그 | E04-01, E04-02 |
| 오류 복구 | E04-02 |
| 관리자 승인 | E04-02 |
| 통합 테스트 | B-INT-01, C-INT-01, DE-INT-01 |

W1-04는 공통 데이터 구조를 정의하는 선행 작업이며, 독립 Agent PoC와 구분한다.

세부 입력 필드는 W1-04 v0.1(PR #1)을 참고하되, 양쪽 문서가 검토 중이므로 최종 승인 시 상호 일치 여부를 재확인한다.
